# SpaceX Falcon 9 First Stage Landing Prediction

**Author:** Kunal Singh  
**Date:** 13 September 2026

## Project Overview

This project analyzes historical SpaceX Falcon 9 launch data and predicts whether the first stage will land successfully.

## Objectives

- Collect and prepare SpaceX launch data.
- Perform exploratory data analysis.
- Analyze data using SQL.
- Create a Folium map and Plotly Dash dashboard.
- Build classification models to predict landing success.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Folium
- SQL
- Scikit-learn
- Jupyter Notebook
